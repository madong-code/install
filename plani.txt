
## 配置说明

### 环境变量

创建 `.env` 文件配置环境变量：

```env
VITE_API_BASE_URL=http://localhost:8000
```

### 公共配置

修改 `src/config/public.ts` 文件自定义配置：

```typescript
export const publicConfig = {
  apiBaseUrl: '/api',
  // ... 其他配置
}
```

## 部署说明

1. 构建项目：`pnpm build`
2. 将 `dist` 目录部署到 Web 服务器
3. 配置后端 API 接口地址

## 浏览器支持

- Chrome >= 88
- Firefox >= 78
- Safari >= 14
- Edge >= 88
